What the operators do

\((\mathbf{P}\mathbf{x})[n]=x[n-1]\)circular delay: \(\mathbf{P}[a\,b\,c\,d]^T=[d\,a\,b\,c]^T\)
\((\mathbf{F}\mathbf{x})[n]=e^{j2\pi n/N}x[n]\)modulation: shifts the spectrum up one bin
\((\mathbf{R}\mathbf{x})[n]=x[-n \bmod N]\)reversal, sample 0 stays put: \(\mathbf{R}[a\,b\,c\,d]^T=[a\,d\,c\,b]^T\)

So in the frequency domain:

  • Multiplying \(X[k]\) by \(e^{-j2\pi mk/N}\) means delaying \(\mathbf{x}\) by \(m\).
  • Multiplying \(X[k]\) by \((-1)^k\) (when \(N\) is even) means circularly shifting \(\mathbf{x}\) by \(N/2\).
  • Multiplying \(x[n]\) by \((-1)^n\) means \(X[k]\to X[k+N/2]\).

Extensions (from the handout)

Periodic, with \(N=ML\): \([\mathbf{s};\mathbf{s};\dots;\mathbf{s}]\) has

\[X[kM]=M\,S[k],\qquad X[\ell]=0 \text{ otherwise}\]

Zero-padded, with \(N=ML\): \([\mathbf{s};\mathbf{0};\dots]\) has

\[Y[kM]=S[k]\]

The other \(Y_\ell\) are interpolated values with no simple formula. Upsampling (zeros between samples): \([a\,0\,b\,0\,c\,0\,d\,0]\) ⟷ \([\mathbf{S};\mathbf{S}]\).

Shortcuts for each problem type

  • Sampling A sinusoid at \(f\) Hz has \(\omega=2\pi f/f_s\), folded into \([0,\pi]\). It lands exactly on a bin only if \(k=fN/f_s\) is an integer. Otherwise it leaks into every bin. So \(N\) has to be a common multiple of each frequency's denominator. Each sinusoid gives 2 bins (\(k\) and \(N-k\)) and DC gives 1.
  • Real signal \(X[N-k]=X[k]^*\). Terms: DC \(=X[0]/N\). Amplitude \(=2|X[k]|/N\) at \(\omega=2\pi k/N\), phase \(=\angle X[k]\). A bin at \(k=N/2\) contributes \(X[N/2]/N\) times \((-1)^n\).
  • Sums Write the weights \(c[n]\) as a combination of \(e^{\pm j2\pi kn/N}\). Then \(\sum x[n]e^{-j2\pi kn/N}=X[k]\) and \(\sum x[n]e^{+j2\pi kn/N}=X[N-k]\). For example, \(2\cos(2\pi kn/N)\) gives \(X[k]+X[N-k]\).
  • Least squares Projecting onto a few Fourier sinusoids keeps those bins. Error \(=\frac1N\sum_{\text{dropped }k}|X[k]|^2\) (Parseval). A constant keeps bin 0, and \([a\,b\,a\,b]\) keeps bins 0 and \(N/2\).
  • Real / imag \(\text{DFT}(\operatorname{Re}\mathbf{s})=\tfrac12(\mathbf{S}+\mathbf{R}\mathbf{S}^*)\) and \(\text{DFT}(j\operatorname{Im}\mathbf{s})=\tfrac12(\mathbf{S}-\mathbf{R}\mathbf{S}^*)\). If \(\mathbf{s}=\mathbf{R}\mathbf{s}^*\) (conjugate-symmetric), then \(\mathbf{S}\) is real.
  • Cosine mod \(y[n]=x[n]\cos(2\pi mn/N)\ \Rightarrow\ Y[k]=\tfrac12(X[k-m]+X[k+m])\). Check whether the shifted copies overlap.
  • Duality To find \(\mathbf{u}\) whose DFT equals a given vector \(\mathbf{w}\): \(\mathbf{u}=\frac1N\mathbf{R}\,\text{DFT}(\mathbf{w})\).
  • Circulant A matrix whose first column is \(\mathbf{h}\) and whose next columns shift it down one each time computes \(\mathbf{h}\circledast\mathbf{u}\). So to solve \(\mathbf{A}\mathbf{u}=\mathbf{b}\): u = ifft(fft(b)./fft(h)).
  • Index puzzles Write the target vector as an operator (\(\mathbf{P}^m\), \(\mathbf{R}\), \(\mathbf{F}^m\)) applied to a known vector. Pattern \([ag\ dh\ ce\ bf]\) is \((\mathbf{R}\mathbf{x})\odot(\mathbf{P}^2\mathbf{y})\), so \(\mathbf{S}=\frac14(\mathbf{R}\mathbf{X})\circledast(\mathbf{F}^{-2}\mathbf{Y})\).
